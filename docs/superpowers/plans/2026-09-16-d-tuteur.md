# D — Tuteur IA : implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une touche `[t]` dans l'atelier donne un indice gradué, jamais la solution, via la chaîne de fournisseurs de l'application.

**Architecture:** Paquet `tuteur/` dans le cours. Un seul appel LLM par indice, contexte construit par le code, niveau décidé par le code. Le schéma `Indice` refuse le code ; ce refus devient `SortieInvalide`, que `generer_valide` puis `executer` gèrent déjà. Quota et consentement dans `.progression.json`.

**Tech Stack:** Python 3.12, pydantic 2.13.5, `fabrique.providers` (repli, chaîne, fake), `fabrique.generation.reparation`, `fabrique.observabilite`.

**Spec:** `docs/superpowers/specs/2026-09-16-parcours-apprenant-design.md` (section 4). Recherche : Bastani et al. PNAS 2025 (https://www.pnas.org/doi/10.1073/pnas.2422633122), Kestin et al. Sci. Rep. 2025 (https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/), CodeHelp (https://arxiv.org/pdf/2308.06921), CS50.ai (https://cs.harvard.edu/malan/publications/V1fp0567-liu.pdf), Anthropic « Building effective agents » (https://www.anthropic.com/engineering/building-effective-agents), injection de prompt (https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/mitigate-jailbreaks).

## Global Constraints

- Niveaux : 1 = quelle vérification échoue et quel concept du chapitre elle touche ; 2 = où regarder (fonction, cas) ; 3 = stratégie en prose ; 4 = `kata.indices[-1]`, sans appel LLM.
- Le niveau suivant n'est débloqué qu'après un nouvel essai `[v]` en échec.
- Quota : 10 jetons, un jeton regagné toutes les 180 secondes, plafond 10.
- Tuteur désactivé si `reglages().chaine == ["fake"]`.
- Consentement explicite au premier `[t]`, qui nomme les fournisseurs de la chaîne et Langfuse si ses clés sont présentes.
- Le code de l'apprenant est transmis encodé en JSON, déclaré comme donnée non fiable dans le prompt système.
- Aucune solution de référence dans le contexte envoyé.
- Texte affiché : français accentué. Commits anglais conventionnels + `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Validation : `.venv/bin/pytest -q`, `.venv/bin/ruff check .`, `.venv/bin/ruff format --check .`, gate, exit 0. Ne jamais lire `.env`. Aucun appel réseau dans les tests.
- Branche : `feat/tutor`, créée depuis la branche du plan C.

```python
"""Ce que le tuteur a le droit de renvoyer : de la prose, jamais du code.

Une consigne « pas de code » ne suffit pas : les modeles penchent vers la
solution complete (CodeHelp, Liffiton et al. 2023). Le refus est donc
deterministe, dans le schema, et repasse par la boucle de reparation.
"""

from __future__ import annotations

import re

from pydantic import BaseModel, Field, field_validator

_INSTRUCTION = re.compile(
    r"^\s*(def|class|return|import|from|for|while|if|elif|else|try|except|with|raise|async|await|yield)\b"
)
_AFFECTATION = re.compile(r"^\s*[A-Za-z_][\w.\[\]]*\s*(=|\+=|-=)\s*\S")


def ressemble_a_du_code(texte: str) -> bool:
    if "```" in texte:
        return True
    lignes = [ligne for ligne in texte.splitlines() if ligne.strip()]
    suspectes = sum(1 for ligne in lignes if _INSTRUCTION.match(ligne) or _AFFECTATION.match(ligne))
    return suspectes >= 1 and (suspectes >= 2 or len(lignes) == suspectes)


class Indice(BaseModel):
    niveau: int = Field(ge=1, le=3)
    texte: str = Field(min_length=1, max_length=600)

    @field_validator("texte")
    @classmethod
    def _pas_de_code(cls, valeur: str) -> str:
        if ressemble_a_du_code(valeur):
            raise ValueError(
                "l'indice contient du code : decris la demarche en phrases, "
                "cite au plus des noms entre backticks"
            )
        return valeur
```
